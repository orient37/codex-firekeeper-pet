# codex-firekeeper-pet
A codex pet from Dark Souls 3 firekeeper

## Install

- copy final-package/firekeeper to ~/.codex/pets 

Just like:
```text
~/.codex/pets/firekeeper/
├── pet.json
└── spritesheet.webp
```

## Start with codex
1. setting -> Mini & Pets.
2. click refressh button
3. choose Firekeeper, and show Mini (Alt+Win+P)
